# TFM Thesis - Master's Thesis Documentation

LaTeX project for writing a Master's Thesis (TFM) in Catalan/Spanish.

## Project Structure

- `main.tex` - Main document file
- `introduction.tex`, `result.tex`, `codi_tempdistrib.tex` - Content sections
- `revision_history.tex`, `gantt_diagrama.tex` - Supporting docs
- `bibliography.bib` - Bibliography references
- `tools/` - LaTeX utilities (packages, styles, acronyms)
- `img/` - Images and logos
- `guides/` - Reference materials

## Reference Materials (guides/)

- `AD_Disease_Odyssey.pdf` - Published paper with context for: State of Art, Methodology, Results sections
- `Master_Thesis_Lucas_Takanori.pdf` - Example thesis structure (2 years old)

## Build

Compile with standard LaTeX tools (pdflatex, bibtex/xelatex). See `dependencies.txt` for required packages.
